# Лапки — календарь с пёсиком

Календарь для работы, тренировок и личных дел: маникюр, встречи с друзьями, врачи, покупки. Работает в браузере на телефоне и компьютере, без интернета тоже. По желанию синхронизируется между устройствами через бесплатную базу Firebase.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html` | Сам календарь |
| `sw.js` | Чтобы календарь открывался без интернета |
| `manifest.webmanifest` | Чтобы можно было поставить значок на экран телефона |
| `icon.svg`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` | Значки |

Все файлы лежат в корне репозитория, без папок.

## Как выложить на GitHub Pages

1. На github.com нажмите «+» → **New repository**. Назовите, например, `lapki`, выберите **Public** и нажмите **Create repository**.
2. На странице репозитория: **Add file → Upload files**. Перетащите все файлы из архива (или выберите их с телефона) и нажмите **Commit changes**.
3. **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две календарь откроется по адресу `https://ВАШ-ЛОГИН.github.io/lapki/`.

### Значок на телефоне
- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте в Chrome → меню → «Добавить на главный экран».

На iPhone у значка на экране «Домой» своё хранилище, отдельное от Safari. Поэтому записи из вкладки Safari там не появятся сами: подключите синхронизацию или перенесите их резервной копией.

### Как обновить
Загрузите новый `index.html` так же: **Add file → Upload files → Commit changes**. Старый файл заменится, записи не пострадают. Если видна старая версия, закройте календарь и откройте снова.

## Синхронизация между устройствами

Без синхронизации записи хранятся только в этом браузере. Чтобы на телефоне и компьютере было одно и то же:

- **Если Firebase уже настроен для «Календаря преподавателя»**, ничего создавать не нужно. Скопируйте там код подключения (`KP1-…`), вставьте его в Лапках: **Настройки → Синхронизация → «Подключить по коду»**. Лапки возьмут из кода вашу базу и заведут в ней отдельный календарь. Записи не перемешаются, правила в Firebase менять не нужно.
- **Если Firebase ещё нет**, откройте **Настройки → Синхронизация → «Первая настройка»**. Там пошаговая инструкция примерно на 10 минут, правила доступа копируются кнопкой.

После подключения в настройках появятся код `LAPKI1-…` и кнопка **«Скопировать ссылку с кодом»**. Откройте эту ссылку на другом устройстве, и календарь подключится сам.

Храните код и ссылку как пароль: по ним открывается ваш календарь.

## Резервная копия

**Настройки → Резервная копия → «Скачать копию»** сохраняет все записи в файл. **«Загрузить из файла»** возвращает их. Пригодится, чтобы перенести календарь без синхронизации.
